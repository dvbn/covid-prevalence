# Prevalence estimation with non-random testing

David Benatia, Raphael Godefroy and Joshua Lewis.

MATLAB estimation example with the supplied U.S. state-level testing data.
Run `run_example.m` from this folder. It estimates the model and stores prevalence
estimates and confidence intervals in `DATA_r`.

Requires MATLAB Optimization Toolbox and Statistics and Machine Learning Toolbox.

## Papers and data

- [Estimating population infection rates from non-random testing data: Evidence from the COVID-19 pandemic](https://doi.org/10.1371/journal.pone.0311001), *PLOS ONE* (2024). [Published supplementary datasets](https://doi.org/10.1371/journal.pone.0311001.s003).
- [Estimates of COVID-19 Cases across Four Canadian Provinces](https://doi.org/10.3138/cpp.2020-03), *Canadian Public Policy* (2020).
